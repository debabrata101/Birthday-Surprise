# Sundari Birthday Surprise 💗

React + React Router + Tailwind CSS + Framer Motion birthday microsite.

## Run
npm install
npm run dev

## Personalize
- Replace `public/her-photo.jpg` with her photo.
- Change `NAME` in `src/main.jsx`.
- Edit the final letter in `Letter()`.

## Flow
Welcome → Teddy + framed photo → 3-layer cake → candle off → birthday → mailbox → balloon interactions → special letter.
